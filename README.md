# The-Forest
A mod for The Paper School (FPE)

This mod focuses on the Kaaatieverse side of the FPE Paper School fangame, where it will have a lot of interesting aspects in the future.
Sneak peek: you'll be able to choose (through conversation) what path you'll take.

Requirements: Paper School Mod (https://err0r4224699.itch.io/fundamental-paper-education-with-paper-school), and a "~mods" folder (See bottom)

Hopefully I can start this mod soon. (I've been getting everything set up)

In the future... IF YOU JUST SEE FEN'S EYE IN THE FOREST, RUN.

# How to set up the mod:
1. Find the "NewFPE" folder
2. Navigate to NewFPE/Content/Paks
3. Create a folder in "Paks" named "~mods" (with the tilde, no quotation marks)
4. Place the .pak file in the ~mods folder
5. Then you can run the game

# Notes:
DO NOT RUN THE GAME WHILE MOVING FILES AROUND.
